# 숫자 맞히기 스펙

## 1. 기술과 파일 구성

### 기술
- Python 3.10 이상
- Flet 1.0
- Flet 문법은 강의서 3~4페이지의 main.py 뼈대에 나온 것만 사용한다. 뼈대에 없는 컨트롤, 속성, 이벤트는 쓰지 않는다.
- 표준 라이브러리만 사용한다. 정답 생성에 `random`, 테스트에 `unittest` 또는 `assert`를 쓴다. pytest 같은 외부 패키지는 쓰지 않는다.

### 파일
| 파일 | 역할 |
|---|---|
| SPEC.md | 이 문서 |
| logic.py | 정답 생성, 입력 검증, 판정, 기록 문자열 만들기. Flet을 import하지 않는다. |
| main.py | Flet 화면과 이벤트 처리. 계산과 검증은 logic.py의 함수를 호출해서 얻는다. |
| test_logic.py | logic.py의 함수만 테스트한다. 화면은 테스트하지 않는다. `python test_logic.py`로 실행할 수 있어야 한다. |

### logic.py가 제공하는 함수
| 함수 | 입력 | 출력 |
|---|---|---|
| new_answer() | 없음 | 1~100 사이 정수 하나 |
| parse_guess(text) | 입력창 문자열 | 올바르면 정수, 잘못되면 ValueError(오류 문구 포함) |
| judge(guess, answer) | 정수 두 개 | "더 큽니다", "더 작습니다", "정답입니다" 중 하나 |
| format_record(n, guess, verdict) | 회차, 입력값, 판정 | "3회차 · 50 · 더 큽니다" 형식 문자열 |

main.py는 숫자 비교, 범위 검사, 문자열 변환을 직접 하지 않는다.

## 2. 동작 규칙

1. 정답은 게임 시작 시 1~100 사이 무작위 정수 하나로 정한다. 같은 게임 중에는 바뀌지 않는다.
2. 입력은 텍스트 입력창과 "확인" 버튼으로 받는다. Enter 키로도 제출된다.
3. 입력 검증(parse_guess):
   - 앞뒤 공백은 제거한다.
   - 남은 문자열이 ASCII 숫자로만 이루어져 있고 값이 1~100이면 올바른 입력이다. 앞의 0은 허용한다(예: "007"은 7).
   - 그 외(빈 칸, 문자, 소수, 부호, 1~100 밖의 숫자)는 잘못된 입력이다. 오류 문구는 "1~100 사이의 정수를 입력하세요"이다.
4. 잘못된 입력은 시도 횟수에 넣지 않고 기록 목록에도 쌓지 않는다. 입력창 아래에 오류 문구만 보여 준다. 입력창의 내용은 그대로 둔다.
5. 올바른 입력은 판정한다.
   - 입력 < 정답: "더 큽니다". 정답이 입력보다 크다는 뜻이다.
   - 입력 > 정답: "더 작습니다". 정답이 입력보다 작다는 뜻이다.
   - 입력 = 정답: "정답입니다".
6. 올바른 입력마다 시도 횟수를 1 늘리고, 기록 한 줄을 목록에 쌓는다. 오류 문구는 지운다. 입력창은 비우고 포커스를 준다.
7. 같은 숫자를 다시 입력해도 정상 시도로 센다. 횟수 제한은 없다.
8. 정답을 맞히면 "N번 만에 맞혔습니다!"를 보여 주고, 입력창과 "확인" 버튼을 비활성화한다. "새 게임"을 누르기 전에는 어떤 입력도 받지 않는다(Enter도 동작하지 않는다).
9. "새 게임"을 누르면 새 정답을 정하고, 목록·시도 횟수·결과 문구·오류 문구를 지우고, 입력창과 "확인" 버튼을 다시 활성화한다.

## 3. 화면 구성

창 하나, 크기 약 400x600, 위에서 아래로 한 열로 배치한다. 모든 문구는 한국어다.

| 순서 | 영역 | 내용 |
|---|---|---|
| 1 | 제목 | "숫자 맞히기" |
| 2 | 안내 | "1부터 100 사이의 숫자를 맞혀 보세요" |
| 3 | 시도 횟수 | "시도 횟수: N" (시작 시 0) |
| 4 | 입력 줄 | 숫자 입력창과 "확인" 버튼을 한 줄에 배치 |
| 5 | 오류 문구 | 입력창 아래. 평소에는 비어 있다. |
| 6 | 결과 문구 | 맞혔을 때만 "N번 만에 맞혔습니다!" 표시 |
| 7 | 새 게임 버튼 | "새 게임". 항상 보이고 언제든 누를 수 있다. |
| 8 | 시도 목록 | 최신이 맨 위. 한 줄 형식은 "3회차 · 50 · 더 큽니다". 항목이 많으면 스크롤된다. |

상태별 화면:
| 상태 | 입력창·확인 버튼 | 결과 문구 | 오류 문구 |
|---|---|---|---|
| 진행 중 | 활성 | 비어 있음 | 잘못된 입력 직후에만 표시 |
| 맞힌 뒤 | 비활성 | "N번 만에 맞혔습니다!" | 비어 있음 |

## 4. 테스트

test_logic.py는 logic.py의 함수만 검사한다. 외부 패키지 없이 표준 라이브러리(`unittest`) 또는 `assert`로 작성한다.

### parse_guess
| 입력 | 기대 결과 |
|---|---|
| "50" | 50 |
| "1" | 1 |
| "100" | 100 |
| " 50 " | 50 |
| "007" | 7 |
| "" | ValueError |
| "   " | ValueError |
| "abc" | ValueError |
| "5a" | ValueError |
| "5.0" | ValueError |
| "50.5" | ValueError |
| "-5" | ValueError |
| "+7" | ValueError |
| "0" | ValueError |
| "101" | ValueError |
| "1e2" | ValueError |
| "５０"(전각 숫자) | ValueError |

### judge
| guess | answer | 기대 결과 |
|---|---|---|
| 30 | 50 | "더 큽니다" |
| 70 | 50 | "더 작습니다" |
| 50 | 50 | "정답입니다" |
| 1 | 100 | "더 큽니다" |
| 100 | 1 | "더 작습니다" |

### format_record
| n | guess | verdict | 기대 결과 |
|---|---|---|---|
| 3 | 50 | "더 큽니다" | "3회차 · 50 · 더 큽니다" |
| 1 | 100 | "더 작습니다" | "1회차 · 100 · 더 작습니다" |
| 7 | 42 | "정답입니다" | "7회차 · 42 · 정답입니다" |

### new_answer
| 검사 | 기대 결과 |
|---|---|
| 1000번 호출 | 모든 값이 정수이고 1 이상 100 이하 |

### 화면 직접 확인 (수동)
| 조작 | 기대 결과 |
|---|---|
| "abc" 입력 후 확인 | 오류 문구 표시, 시도 횟수와 목록 변화 없음 |
| 올바른 숫자 입력 | 횟수 +1, 목록 맨 위에 한 줄 추가, 입력창 비워짐 |
| 같은 숫자를 두 번 입력 | 두 번 모두 기록됨 |
| 정답 입력 | "N번 만에 맞혔습니다!", 입력창·확인 버튼 비활성 |
| 정답 후 Enter | 아무 일도 일어나지 않음 |
| 새 게임 | 목록·횟수·문구 초기화, 입력창 활성 |
