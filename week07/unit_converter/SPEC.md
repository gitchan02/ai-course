# 단위 변환기 스펙

## 1. 기술과 파일 구성

### 기술
- Python 3.10 이상, Flet 1.0. 다른 패키지는 쓰지 않는다. 파이썬에 들어 있는 모듈만 쓴다.
- Flet 문법은 강의서 3~4페이지의 main.py 뼈대에 나온 것만 쓴다. 뼈대에 없는 Flet 클래스, 인자, 속성은 쓰지 않는다.
- Flet 1.0에 없는 `ft.app(...)`, `ft.colors`, `ft.alignment.center`, `ft.ElevatedButton`, `Button(text=...)`, `page.window_width`, `ft.UserControl`, `TextField(error_text=...)`는 쓰지 않는다.

### 파일
| 파일 | 내용 |
|---|---|
| SPEC.md | 이 문서 |
| logic.py | 계산과 판정. Flet을 import하지 않는다. 입력을 받아 결과와 안내 문구를 돌려주는 함수만 있다. |
| main.py | 화면. 뼈대를 넓힌 것. 계산과 검사는 전부 logic.py의 함수를 불러서 한다. |
| test_logic.py | logic.py의 함수를 검사한다. 실행하면 통과와 실패를 출력한다. |

### logic.py가 제공하는 것
| 이름 | 입력 | 출력 |
|---|---|---|
| UNITS | - | 단위 목록 `["mm", "cm", "m", "km", "°C", "°F"]` |
| convert(text, from_unit, to_unit) | 입력창 문자열, 변환 전 단위, 변환 후 단위 | `(결과 문자열, 안내 문구)`. 성공하면 안내 문구가 빈 문자열이고, 실패하면 결과 문자열이 빈 문자열이다. |
| format_number(x) | 숫자 | 소수 6자리까지 반올림하고 끝의 0을 지운 문자열 |

main.py에는 숫자 변환, 단위 계산, 범위 검사, 자릿수 처리가 없다.

## 2. 동작 규칙

1. 단위는 길이(mm, cm, m, km)와 온도(°C, °F) 여섯 개다. 변환 전과 후 두 목록에 모두 들어 있다.
2. 변환은 "변환" 버튼을 눌렀을 때만 한다. 값이나 단위를 바꾸기만 해서는 결과가 바뀌지 않는다.
3. 입력 검사는 다음 순서로 하고, 먼저 걸린 것의 안내 문구만 보여 준다.
   1. 숫자가 아니면 "숫자를 입력하세요".
      - 앞뒤 공백은 지우고 읽는다. 소수와 `1e2` 같은 지수 표기는 숫자로 본다.
      - 빈 칸, 문자, 쉼표(`1,000`), 밑줄(`1_000`), 전각 숫자(`５０`), `nan`, `inf`는 숫자가 아니다.
   2. 길이와 온도를 섞어 고르면(예: cm → °C) "길이와 온도는 서로 변환할 수 없습니다".
   3. 길이 단위에서 값이 음수이면 "길이는 0 이상이어야 합니다". 온도는 음수를 허용한다. 절대영도 아래인지는 검사하지 않는다.
   4. 계산 결과가 너무 커서 무한대가 되면 "값이 너무 큽니다".
4. 오류이면 결과 칸을 비우고 안내 문구를 보여 준다. 성공하면 안내 문구를 지우고 결과를 보여 준다.
5. 길이는 미터를 거쳐 변환한다. mm = 0.001 m, cm = 0.01 m, m = 1 m, km = 1000 m.
6. 온도는 °F = °C × 9 / 5 + 32, °C = (°F − 32) × 5 / 9로 변환한다.
7. 같은 단위를 고르면(예: cm → cm) 오류가 아니라 정상 변환으로 보고 입력한 값을 그대로 결과로 보여 준다.
8. 결과는 소수 6자리까지 반올림하고 끝의 0과 불필요한 소수점을 지운다. `-0`은 `0`으로 보여 준다. 예: 100 cm → m는 `1`, 1 °F → °C는 `-17.222222`.

## 3. 화면

창 하나, 크기 360 x 480, 크기 조절 불가. 창 제목은 "단위 변환기". 모든 문구는 한국어다.

| 순서 | 요소 | 내용 |
|---|---|---|
| 1 | 입력 줄 | `TextField`(라벨 "값", 처음 값 "100")와 `Dropdown`(라벨 "단위", 처음 값 cm)을 한 줄에 둔다. |
| 2 | 화살표 | 글자 "↓" |
| 3 | 결과 줄 | 글자 "결과", 결과를 보여 주는 `Text`(처음에는 비어 있음), `Dropdown`(라벨 "단위", 처음 값 m)을 한 줄에 둔다. |
| 4 | 변환 버튼 | "변환". 파란 배경에 흰 글자. |
| 5 | 안내 문구 | 빨간 글자. 평소에는 비어 있다. |

- 결과 칸은 읽기 전용 속성이 뼈대에 없으므로 `Text`로 만든다. 그림의 입력창 모양과 다르다.
- 두 `Dropdown`의 목록은 `UNITS`의 여섯 개다.
